# Deployment

VOIDS VISION V1 is a static site and can be hosted on GitHub Pages. Camera access requires a secure context; localhost is allowed for development and production hosting should use HTTPS.

## GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save and wait for GitHub Pages to publish the site.
6. Open the published HTTPS URL and allow camera permission.

After deployment, smoke-test camera startup, pinch/release, Air Draw, Presentation, Spatial/Holo, Save/Load and exports.
