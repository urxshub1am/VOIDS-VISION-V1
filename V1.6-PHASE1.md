# VOIDS VISION V1.6 DEV — Spatial Interaction Pro · Phase 1

Development marker for the `v1.6-dev` branch. Phase 1 is focused on one-hand 3D primary control modes (Move / Rotate / Depth), safer mode handoff into the existing free-space second-hand manipulator, snap-aware primary transforms, exact 3D selection priority over overlapping 2D bodies, and clearer Spatial transform telemetry.

`main` remains the stable V1.5.4 release and should not be used for V1.6 development until runtime validation is complete.
