# VOIDS VISION V1.7 RC1 — Experience & Reliability

Feature-frozen release candidate built from the Phase 6 runtime candidate.

RC1 includes Onboarding V2, HUD/Spatial UX cleanup, measured performance-pressure protection, Settings V2 quick profiles, the eight-step Guided Workspace Tour, and recovery/accessibility fallbacks.

Packaging rule: Phase 6 JavaScript, CSS, assets/models and interaction behavior remain unchanged. Only RC labeling, documentation and the test package change in this pass.

`main` remains the V1.6 stable release until the RC1 browser acceptance gate passes.
