VOIDS VISION V1.6 — SPATIAL INTERACTION PRO

This is the feature-frozen release candidate. Do not merge it over an older build.

RUN
1. Extract this ZIP into a NEW empty folder.
2. Open the extracted folder in VS Code.
3. Run index.html through Live Server / localhost (do not use file://).
4. Use current Chrome or Edge and allow camera permission.
