VOIDS VISION V1.5.4 — ADAPTIVE MOTION SMOOTHING

1. Extract this ZIP into a NEW empty folder. Do not merge it over an older VOIDS VISION version.
2. Open the VOIDS-VISION-V1.5.4 folder in VS Code.
3. Run index.html through Live Server / localhost (do not use file://).
4. Use current Chrome or Edge and allow camera permission.


V1.5.4 ADAPTIVE MOTION SMOOTHING
- Pointer aim is stabilized against palm motion instead of relying only on fingertip samples.
- Pinch/capture freezes fingertip offset learning so finger curl does not kick the cursor.
- Low-FPS High Precision is less sticky while deliberate movement stays responsive.
- Sparse tracking samples are visually resampled for smoother cursor travel.
- Spatial hover follows the visible pointer; empty-space aim no longer forces full 3D redraws.
- 3D material/bounds work is cached/throttled and active hand transforms interpolate visually.
- V1.5.3 SVG/runtime recovery and all V1.5.2 reliability protections remain preserved.

V1.5.3 RUNTIME + AIM STABILITY
- Spatial SVG surface releases no longer leak into the normal DOM click path (`target.click` crash fixed).
- Generic Spatial input/UI faults no longer force a healthy WebGL scene into Canvas fallback.
- Shape / Hologram Library can self-restore if its DOM nodes are lost during recovery.
- High Precision aim adds extra low-FPS micro-jitter damping while deliberate movement stays responsive.
- V1.5.2 tracking/reacquisition/free-space transform reliability remains preserved.

V1.5.2 TRACKING RELIABILITY
- H1/H2 identity is preserved through ambiguous hand overlap instead of creating fresh IDs.
- Low-FPS tracking/reacquisition timing adapts to the measured inference rate.
- Critical pinch still requires two real samples, but slow cameras no longer wait unnecessarily for a third sample.
- Short Anchor/Manipulator gaps freeze the transform, then rebase before resuming to prevent jumps.
- Free-space palm control and 3D transforms use adaptive jitter smoothing plus bounded transform slew.
- AUTO intent selection re-centers the baseline when SCALE/ROTATE locks, preventing the lock frame from jumping the object.
- Very low FPS triggers tracking-priority 3D rendering sooner.

V1.4.1 STABILITY FIXES
- Reset Transform restores each native shape's real default orientation instead of forcing every rotation to 0°.
- Undo/Redo imported-model history is memory-bounded; heavy editing may prune the oldest undo/farthest redo history instead of allowing unbounded RAM growth.
- Image hologram history no longer repeatedly deep-copies large Base64 payloads during normal edits.
- Portable workspace JSON warns around 32 MB and is capped at 64 MB. The existing model import limit remains 14 MB per selection and 12 distinct live imported-model assets.
- Imported models auto-play one valid animation clip instead of several clips at the same time.
- PNG export snapshots the WebGL layer immediately to reduce blank/missing 3D exports.
- Three.js model-loader module requests time out after 12 seconds and failed model nodes retry after leaving/re-entering Spatial.
- Hidden objects are blocked from precise/keyboard/gesture transforms until shown again.
- Accidental model-file drops outside the Holo board/drop zone no longer navigate the browser away from an unsaved workspace.
- Draco/Meshopt/BasisU-compressed glTF files are intentionally rejected in this build; export an uncompressed GLB for the most reliable import.

NEW IN V1.4 — SPATIAL WORKSPACE PRO
- Scene Objects list lets you select every 3D object, including hidden objects.
- Rename 3D objects; names persist in Workspace Save/Load.
- Hide/Show and Lock/Unlock controls are available per object. Locked objects cannot be moved, transformed, or deleted until unlocked.
- Precise transform controls: Move X/Y/Z, Rotate X/Y/Z, and uniform Scale. Each step is Undo/Redo-safe.
- Focus Selected moves the 3D camera target to the selected object. Scene Center returns the 3D view to origin.
- Geometry telemetry shows cached mesh/triangle counts when WebGL data is ready.
- Keyboard: Arrows = X/Y, Page Up/Down = Z, [ ] = rotate Y, -/+ = scale, F = focus, L = lock. Shift makes movement steps larger.
- Workspace schema is now v3. Older schema-v1/v2 projects remain supported.

NEW IN V1.3.2
- Real 3D import accepts GLB, GLTF, OBJ, STL and FBX.
- The file picker shows all files. Unsupported formats now produce a clear error instead of silently disappearing.
- GLB is still the recommended format.
- Import limit: 14 MB total per model selection.
- Once a 3D object is grabbed by the Anchor hand, the second hand NO LONGER needs to aim at the same object or stay over the Holo board.
- Keep the second hand physically separate, place it anywhere in camera view, pinch, and it joins as Manipulator.
- Change the distance/angle between hands to scale and rotate. Releasing Manipulator leaves Anchor holding.

3D IMPORT NOTES
- GLTF: select .gltf + required .bin + PNG/JPG/WebP companion files together.
- OBJ: geometry imports as a holographic model. External MTL texture packages are not required for the hologram look.
- STL: geometry-only import.
- FBX: self-contained files work best; external texture dependencies may not be portable.
- ZIP files must be extracted first.
- Very large/high-poly models can reduce FPS. The app rejects imports over 14 MB.
- Workspace JSON files are VOIDS VISION project files, not 3D models.

V1.3.4 HARDENING
- Import and reload now enforce the same 12 distinct imported-model asset limit.
- Large embedded model assets are cleaned up once they are no longer reachable from the workspace or Undo/Redo history.
