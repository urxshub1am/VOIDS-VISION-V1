# VOIDS VISION V1.7 DEV — Experience & Reliability · Phase 4

Phase 4 focuses on Settings V2 and profile simplification while preserving the tested V1.6/V1.7 gesture and Spatial interaction core.

Runtime candidate highlights:
- Quick profiles: Performance / Balanced / Precision
- Progressive disclosure for Pointer, Spatial, Display/Camera and locked diagnostics
- Precision profile uses the existing High Precision pointer mode plus lower Spatial transform sensitivity
- Existing `voids-vision.settings.system.v1` and `voids-vision.settings.precision.v1` storage formats remain compatible
- Gesture geometry, pinch/release thresholds, hold timing, cooldowns, hand association and Spatial transform math remain unchanged

`main` remains the V1.6 stable release until V1.7 runtime validation is complete.
