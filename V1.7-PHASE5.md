# VOIDS VISION V1.7 DEV — Experience & Reliability · Phase 5

Phase 5 adds a non-destructive Guided Workspace Tour for the live demo path while preserving the tested V1.6/V1.7 interaction core.

Runtime candidate highlights:
- one-button Workspace Tour from Demo / Learn
- fixed path: Home → Pointer → Air Draw → Presentation → Spatial → Gesture Lab → Challenge → Home
- persistent floating step overlay with Back / Next / Exit controls
- manual progression only; no fake gesture success and no automatic destructive actions
- drawings, Spatial scenes, settings, Challenge scoring and camera/tracker state are preserved
- gesture geometry, pinch/release thresholds, hand association and Spatial transform math remain unchanged

`main` remains the V1.6 stable release until V1.7 runtime validation is complete.
